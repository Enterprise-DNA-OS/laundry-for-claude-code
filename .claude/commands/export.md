# Take a portable backup

Use export --out=exports/<dated-name>.json after creating exports/. The output contains personal data and must stay private. Every table is included. Existing files are never overwritten.

Run:

```bash
node scripts/laundry.mjs help
```

Use `--json` when inspecting records. Never guess a match or invent missing data.
