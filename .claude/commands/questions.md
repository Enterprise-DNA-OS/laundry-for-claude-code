# Ten questions from the records

Run all ten or a numbered question. Empty results mean no matching records, not missing functionality. These are extensible local questions, not a verified claim that CleanCloud cannot answer them.

Run:

```bash
node scripts/laundry.mjs questions $ARGUMENTS
```

Use `--json` when inspecting records. Never guess a match or invent missing data.
