# Record an order event

Read order for the requested ticket. Use log <ticket> --actor=<name> --note=<confirmed event>. State who observed it. Do not claim work was done unless the operator says it was.

Run:

```bash
node scripts/laundry.mjs help
```

Use `--json` when inspecting records. Never guess a match or invent missing data.
