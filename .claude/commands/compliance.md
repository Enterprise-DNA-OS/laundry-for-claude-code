# Care, claims and chemical records

Read docs/compliance.md. Report statutory record checks separately from internal operating controls. An empty result is not certification. Read substances for the chemical register. Use review-substance to record verified SDS and inventory details.

Run:

```bash
node scripts/laundry.mjs compliance
```

Use `--json` when inspecting records. Never guess a match or invent missing data.
