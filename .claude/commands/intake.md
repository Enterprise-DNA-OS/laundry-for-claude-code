# Count and tag incoming garments

Read customers and stores. Add an order with an agreed due date, then add one garment per tag with the manufacturer care label and observed intake condition. Run order to verify counts. Use amend-garment to correct observed care and condition records. Never infer either from fabric type.

Run:

```bash
node scripts/laundry.mjs help
```

Use `--json` when inspecting records. Never guess a match or invent missing data.
